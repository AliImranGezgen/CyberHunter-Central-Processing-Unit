# systemd Unit'leri

- Uzantısı doğrudan `.service`/`.timer` olan Inbox Worker dosyaları tam kaynaklardan alınmıştır.
- `.example` dosyaları terminalde görülen gerçek unit içeriklerinden anonimleştirilmiş/temizlenmiş örneklerdir.
- Mutlak yollar, kullanıcı/grup adları ve `ReadWritePaths` hedef sistemde doğrulanmadan kurulum yapılmamalıdır.
