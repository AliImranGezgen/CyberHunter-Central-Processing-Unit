ESP32 olay şeması:

  event_id            : metin
  timestamp           : metin
  source_ip           : metin
  destination_port    : tam sayı
  protocol            : metin
  event_type          : metin
  command             : metin
  tactic              : metin
  risk_score          : tam sayı

ESP32 değer kontrolleri:

  event_id            : boş değil, en fazla 40 karakter
  timestamp           : UTC Z son ekli tarih-saat biçimi
  command             : en fazla 256 karakter
  destination_port    : 1–65535
  risk_score          : 0–100

Timestamp kontrolü:

- YYYY-MM-DDTHH:MM:SSZ temel biçimi kontrol edilir.
- İsteğe bağlı kesirli saniye bölümü desteklenir.
- Ay, gün, saat, dakika ve saniye sınırları kontrol edilir.
- Şubat ve artık yıl gün sayısı hesaplanır.

Hata kodları:

  invalid_json      : JSON ayrıştırma veya kök nesne hatası
  invalid_schema    : Eksik alan veya yanlış veri türü
  invalid_value     : Değer, uzunluk veya aralık hatası
  aes_auth_failed   : AES-GCM doğrulama/şifre çözme hatası

ESP32 cevap alanları:

  event_id
  device_id
  input_risk_score
  esp32_risk_score
  decision
  processed

processed anlamı:
processed alanı, backend HTTP kayıt işleminin başarılı 2xx cevapla
tamamlanmasına göre belirlenmektedir. Yalnızca JSON ayrıştırmasının başarılı
olduğu anlamına gelmez.

Frame doğrulamaları:

- 32 bayt frame uzunluğu
- Magic ve protokol sürümü
- Frame türü
- CRC-16
- Message ID
- Sequence
- Toplam frame sayısı
- Payload uzunluğu
- Toplam blob uzunluğu
- Eksiksiz yeniden birleştirme

Kritik güvenlik bulgusu:
Ham firmware kaynak kodunda Wi-Fi kimlik bilgileri, servis URL'leri ve 32
baytlık AES anahtarı gömülü olarak bulunmaktadır. Değerlerin kendileri bu
kanıta alınmamıştır.

Ham CyberHunterV2.ino dosyası mevcut hâliyle public repoya eklenmemelidir.
Gerçek değerler daha önce public olarak paylaşıldıysa Wi-Fi parolası ve AES
anahtarı değiştirilmelidir.

Kapsam sınırı:
Kaynak dosyanın çalışan ESP32 binary'siyle kriptografik olarak aynı olduğu
attestation yöntemiyle doğrulanmamıştır. Derleme ve karta yükleme kanıtı Stage
18 kapsamında ayrıca ele alınacaktır.
