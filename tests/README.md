# Test Alanları

- `unit/`: saf Python davranışları
- `integration/`: dosya kuyruğu ve servis entegrasyonu
- `security/`: izinler, secret ve sertleştirme kontrolleri
- `hardware/`: I²C, ESP32 ve röle testleri

Donanım gerektiren testler CI'da zorunlu değildir; Raspberry üzerinde tarihli sonuç dosyası üretmelidir.
