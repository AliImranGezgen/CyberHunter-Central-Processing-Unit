# 03 — İşletim Sistemi Kurulumu

USB bellekten boot denemeleri ve güç/LED gözlemlerinden sonra microSD üzerinden kurulum yapıldı. Raspberry Pi OS ile ilk ağ/SSH testi gerçekleştirildi; aktif çalışma sistemi olarak Ubuntu Server 24.04.4 LTS (`noble`, `arm64`, Raspberry kernel) seçildi.

Hostname `cyberhunter-pi`, saat dilimi `Europe/Istanbul` olarak ayarlandı. Sürüm, mimari, kernel, hostname ve NTP çıktıları `evidence/command-outputs/` altında anonimleştirilmiş `.txt` dosyalarıyla kanıtlanmalıdır.
