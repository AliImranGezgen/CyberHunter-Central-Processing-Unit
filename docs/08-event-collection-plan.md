# 08 — Olay Toplama Planı

Toplanan temel alanlar: bağlantı zamanı, kaynak IP/port, hedef port, protokol, servis, kullanıcı adı denemesi, komut, oturum kimliği, bağlantı süresi, dosya yükleme girişimi ve hata bilgisi.

Kaynak veriler değiştirilemez ham kanıt olarak korunur; normalleştirilmiş kayıtlar ayrı dosyaya yazılır. Parola ve özel anahtar gibi kimlik bilgileri analiz için zorunlu değilse tutulmamalı, kanıtlarda hiçbir zaman yayınlanmamalıdır.
