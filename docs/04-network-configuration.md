# 04 — Ağ Yapılandırması

Üniversite ortak Ethernet/kablosuz ağıyla doğrudan bağlantı denemesi sonuç vermedi. Geliştirme için bilgisayar üzerinden mobil erişim noktası oluşturuldu ve Raspberry Pi kablosuz olarak bağlandı.

Repo içerisinde gerçek SSID, parola, MAC, gateway veya IP tutulmaz. Örneklerde `<WIFI_SSID>`, `<WIFI_PASSWORD>` ve `192.168.X.X` biçimi kullanılır. Üretim ağ topolojisi, geçici hotspot ve ngrok bağımlılıklarından ayrılmalıdır.
