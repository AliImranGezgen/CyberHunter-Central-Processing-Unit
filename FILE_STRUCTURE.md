# Dosya Yapısı

| Yol | Amaç |
|---|---|
| `docs/` | Teknik açıklamalar, stage kayıtları ve süreç politikaları |
| `src/` | Tam içeriği doğrulanmış kaynak kodlar |
| `scripts/` | Tekrar kullanılabilir kurulum/doğrulama/bakım betikleri |
| `configs/examples/` | Gizli bilgi içermeyen yapılandırma örnekleri |
| `configs/systemd/` | Doğrulanmış veya açıkça `.example` etiketli unit dosyaları |
| `tests/` | Birim, entegrasyon, güvenlik ve donanım testleri |
| `evidence/` | Komut çıktısı, ekran görüntüsü, fotoğraf ve test sonucu |
| `examples/` | Yapay ve anonim örnek olaylar |
| `.github/` | PR/issue şablonları, CODEOWNERS, CI ve repo ayarları |
